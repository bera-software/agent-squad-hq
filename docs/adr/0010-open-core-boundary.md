# ADR-0010: Open-core licensing boundary

- **Status:** Accepted
- **Date:** 2026-10-21

## Context

The project is published as open source with possible commercial editions later.

## Decision

Everything in this repository is Apache-2.0. Contributions are accepted under the Developer Certificate of Origin rather than a CLA. Any future commercial code will live in a separately licensed directory. Security gates and safety controls always remain in the open-source edition; paid editions add scale, governance and integrations.

## Consequences

Maximum adoption and a patent grant. Competitors may host the open-source core; differentiation is in hosting, governance and support.

## Alternatives considered

AGPL and source-available licences were considered and rejected for adoption reasons.
